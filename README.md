# Booki — Hébergements et activités touristiques

## Présentation

Ce projet a été réalisé dans le cadre de la formation OpenClassrooms. Il consiste à intégrer une interface de recherche d'hébergements et d'activités touristiques à Marseille à partir de maquettes.

## Technologies utilisées

- **HTML5** : structure et contenu des pages.
- **CSS3** : mise en forme et présentation.
- **Flexbox** : organisation des éléments.
- **Media queries** : adaptation de la mise en page aux différentes tailles d'écran.

## Fonctionnalités de l'interface

- Navigation vers les sections Hébergements et Activités.
- Barre de recherche et filtres visuels.
- Cartes présentant des hébergements et des activités.
- Mise en page responsive pour ordinateur, tablette et mobile.

_La recherche et les filtres constituent des éléments d'interface visuelle ; aucune fonctionnalité de recherche côté serveur n'est implémentée._

## Lancer le projet en local

Ouvrir le fichier `index.html` dans un navigateur web.

Le site sera publié avec GitHub Pages. Le lien sera ajouté après le déploiement.
